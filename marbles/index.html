How the fair score works
  1. Each finisher earns 30 base points.
  2. Placement adds 0–70 bonus points: first gets 70, last gets 0.
  3. A DNF earns 0 points.
  4. Finishing all three marbles adds 15% bonus.
  5. Drop is divided in proportion to final scores.
